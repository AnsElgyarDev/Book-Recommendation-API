# Book Recommendation API

A .NET Web API project integrated with the Google Books API to manage and fetch book data, featuring automated search caching and a smart recommendation hub.

##  Getting Started

To clone and run this repository locally, use the following commands:

```bash
git clone [https://github.com/AnsElgyarDev/Book-Recommendation-API.git](https://github.com/AnsElgyarDev/Book-Recommendation-API.git)
cd Book-Recommendation-API
dotnet restore
dotnet run --project BookRecommendationAPI/BookRecommendationAPI.csproj
```

🛠️ Tech Stack
Language: C#

Framework: .NET Web API

Integration: Google Books External API

Version Control: Git & GitHub
